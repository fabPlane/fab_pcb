`GetItemsPagingAndChangesSinceRevision`. `be90a7e200` also changed

This one went in as `Sync: Keep the commit push from bumping the revision twice` rather than a
fixup — squashing it into `API: Add GetDocumentRevision` conflicted across a ~170-line region,
because the surrounding code evolves substantially in later series commits. Compile-bisectability
is unaffected; the double bump was a runtime fault.
