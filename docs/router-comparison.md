# Router comparison

Generated by `bun run --filter @fp-pcb/router bench` (`packages/router/bench/run.ts`). Each row: the board's
`*.unrouted.kicad_pcb` variant opened on a fresh `kicad-cli api-server`, then the **bridge job** — the code path
the app's Autoroute dialog runs (`packages/router/src/bridge-job.ts`: `RefillZones` -> `SaveDocument` ->
`extractRouteInput` -> route -> `applyRouteResult` as one commit) — with the board's own net-class rules, followed
by `RefillZones` + `RunBoardJobDrc`.

"Routed / total" is measured with KiCad's connectivity: `GetUnroutedCount` before the job minus after it, zones
refilled both times. "Router said" is the router's own count of the same connections — a net counts as routed for
the router as soon as it got a wire, which overstates on multi-pad nets; the app shows both when they differ.
"DRC errors" excludes `unconnected_items` (that is the completion column) and shows the count on the unrouted board
in parentheses, so pre-existing problems are visible. Wall time is the whole job (refill, save, extract, route, apply,
re-measure); the router alone is in the notes. Raw JSON and SVG renders: `packages/router/bench/results/`.
